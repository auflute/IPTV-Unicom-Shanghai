# 上海联通本地 IPTV

本项目提供上海联通本地 IPTV 频道地址，支持时移（需使用 DIYP 或 APTV）。

> ⚠️ 注意：仅限上海联通本地网络可用。  
> 使用魔法时，请将相关 IP 加入到直连分流规则中。

## EPG 节目单

可用的 EPG 地址如下：

- [EPG 1](https://epg.112114.xyz/pp.xml)  
- [EPG 2](http://epg.51zmt.top:8000/e.xml)  
- [EPG 3](https://epg.pm/xmltv/epg.xml)  

DIYP 的 EPG 可使用：

- https://epg.112114.xyz/

## 使用方法

1. 在网页上点击 `txt` 或 `m3u` 文件。
2. 点击右上角的 **Raw** 打开页面。
3. 复制 Raw 页面链接到直播软件中，导入节目列表即可。
